# Contributing

This repository is my own lab work for CSE115L, so I will review every change before merging it. Suggestions to improve the code are welcome.

## Suggesting a change

- Open an **issue** to describe a bug or an improvement.
- Or open a **pull request** with the change.

## Pull requests

1. Fork this repository and create a branch.
2. Keep each change small and limited to one task or file.
3. Make sure the code compiles with no warnings:
   ```
   gcc -Wall -Wextra file.c -o file
   ```
4. Keep to the style of the existing code: plain C, simple and readable.
5. Explain in the pull request what you changed and why.

Please be respectful and constructive.
